Ранняя орбита

Sputnik — техническое превью. Синтаксис, API и форматы артефактов ещё меняются. Пробуйте, исследуйте, сообщайте об ошибках; стабильность для production пока не обещается.

01 / SYNTAX

Выразительность в каждой строке

Отступы, блоки, pattern matching и несколько клаузул def. Классы, mixin, интерполяция строк и коллекции с spread.

02 / EXECUTION

Один язык. Два пути исполнения.

Быстрый цикл разработки в VM и сборка нативного исполняемого файла. Строгий режим --require-full-native проверяет отсутствие fallback в VM.

03 / CONCURRENCY

Параллельность без глобального lock

VM без GIL: системные потоки, strands, кооперативные задачи, каналы и структурированная отмена.

01 / FIRST CONTACT

Меньше церемоний. Больше смысла.

Коллекции, блоки и функции остаются рядом с задачей. Последнее выражение становится результатом.

orbit.s 
def square(x):
  x * x

squares = [1, 2, 3, 4].map: square(_1)
squares
# [1, 4, 9, 16]

04 / LAUNCH SEQUENCE

Попробовать Sputnik

Нужны C++17, make и OpenSSL. Обычный make собирает пользовательский CLI; тесты запускаются отдельно.

Выбирайте .s для повседневного кода, .spu для Sputnik Program Unit или .sputnik для выразительного имени. Семантика одинакова.

TERMINAL 
git clone https://github.com/orlando-labs/amber-lang.git sputnik-lang
cd sputnik-lang
make -j4

printf 'p("Hello, orbit!")\n' > hello.s
build/sputnik run hello.s
build/sputnik build hello.s -o hello
./hello
